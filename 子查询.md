

## 子查询



请帮我查找工资比Abel这个人高的员工的姓名和salary

两种写法：

*   自连接（两张表，一张表用于锁定，一张表用于）

```sql
SELECT  m.last_name,m.salary
FROM employees e,employees m
WHERE e.last_name='Abel' AND m.salary >e.salary; 
```



*   子查询

一个 SELECT 语句里嵌套另一个 SELECT，写在括号里，子查询的结果被主查询使用

```sql
SELECT last_name,salary
FROM employees
WHERE salary > (
                  SELECT salary
                  FROM employees
                  WHERE last_name = 'Abel'
                );
```



### 单行子查询

**整个子查询返回的结果只有一条**



*   查询工资大于149号员工的工资的员工信息（只返回149号员工的工资）

```sql
SELECT last_name,salary
FROM employees
WHERE salary > (
                SELECT salary
                FROM employees
                WHERE employee_id = 149
               );
```

*   **操作符：**`= > < >= <=  <> `



### 多行子查询

**整个子查询的结果返回了多条**

*   返回job_id与141号员工相同，salary比143号员工多的

````sql
SELECT last_name,salary,job_id
FROM employees
WHERE job_id = (
                SELECT job_id
                FROM employees
                WHERE employee_id = 141
                ) 
AND salary > (
                SELECT salary
                FROM employees
                WHERE employee_id = 141
               );
````







多行子查询的运算符：

​	`IN` （等于子查询中的结果集合中的任意一个值即可）

​	`ANY`（需要和单行运算符一起使用的，表示的是和子查询返回的结果中的某一个值进行比较）

​		比如说 > ANY(10,20)，就是大于10或者20任意一个即可

​	`ALL`（和子查询中返回的所有的值进行比较）



*   返回其它 job_id 中比 job_id 为‘IT_PROG’的部门任意工资低的员工的员工号、姓名、job_id 以及salary

```sql
SELECT employee_id,last_name,job_id,salary
FROM employees
WHERE salary < ANY (
                      SELECT salary
                      FROM employees
                      WHERE job_id = 'IT_PROG'
                   ) AND job_id <> 'IT_PROG' 

```



*   查询平均工资最低的部门id

```sql
SELECT department_id 
FROM employees
GROUP BY department_id
HAVING AVG(salary) <=ALL (
                            SELECT AVG(salary)
                            FROM employees
                            GROUP BY department_id
                           ) ;
```











*   ==**HAVING中的子查询**==

查询最低工资大于**50号部门最低工资**的部门id和其最低工资

```sql
SELECT department_id,MIN(salary)
FROM employees
GROUP BY department_id
HAVING MIN(salary) < (
                      SELECT MIN(salary)
                      FROM employees
                      WHERE department_id = 50
                     );
```



子查询最终的结果是空的，那么整个查询最终不会报错，但是返回的是空的结果







### 不相关子查询

*   查询大于整个公司平均公司的员工

```sql
SELECT last_name, salary
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees);
```



子查询**没用到外层的任何列**，自己就能独立执行，算出"公司平均工资"这一个值。然后外层拿这个值去逐行比较。

**执行过程**：

1.  先执行子查询 → 得到平均工资（比如 6461）
2.  外层查询拿 6461 逐行判断 `salary > 6461`

**特点**：子查询只跑 1 次，效率高





### 相关子查询

*   查询当前大于部门平均工资的员工

```sql
SELECT last_name, salary, department_id
FROM employees e
WHERE salary > (SELECT AVG(salary) FROM employees i
                WHERE i.department_id = e.department_id);
```



看子查询里的 `e.department_id`——**e 是外层查询的表**！子查询必须知道"当前外层这一行是哪个部门"，才能算这个部门的平均工资。所以它**不能单独执行**。

**执行过程**（逐行循环）：

1.  外层取第 1 行（比如张三，部门 50）
2.  子查询算"部门 50 的平均工资" → 拿张三的 salary 比较
3.  外层取第 2 行（比如李四，部门 80）
4.  子查询算"部门 80 的平均工资" → 拿李四的 salary 比较
5.  ……外层有多少行，子查询就执行多少次

**特点**：子查询执行次数 = 外层行数，效率较低，但能表达"按行取不同基准"的逻辑。





*   ==**CASE里的子查询**==

显示员工的 employee_id、last_name。若员工所属部门的 location_id 为 1800，则 location 显示为 'Canada'，否则显示为 'USA'。

```sql
SELECT e.employee_id, e.last_name,
  CASE (SELECT d.location_id FROM departments d
        WHERE d.department_id = e.department_id)
    WHEN 1800 THEN 'Canada'
    ELSE 'USA'
  END AS location
FROM employees e;
```





内部的子查询使用到了外部查询的表，并且进行了条件的关联，每次执行外部查询的时候，子查询都要重新运算



*   查询员工的id，salary，按照department_name进行排序

```sql
SELECT employee_id,salary
FROM employees e
ORDER BY (
        SELECT department_name
        FROM departments
        WHERE e.department_id = departments.department_id
         );
         
或者

SELECT e.employee_id, e.salary
FROM employees e
JOIN departments d ON e.department_id = d.department_id
ORDER BY d.department_name;
```



*   查询员工中工资大于本部门平均工资的员工的last_name,salary和其department_id

```sql
SELECT last_name,salary,department_id
FROM employees e
WHERE salary > (
                SELECT AVG(salary)
                FROM employees i
                WHERE  i.department_id = e.department_id

);
```







**EXISTS  :存在**

​	**语义**：子查询**存在（至少查到一行）** → TRUE → 该行保留



**NOT  EXISTS：判断**

​	**语义**：子查询**不存在（一行都查不到）** → TRUE → 该行保留。

==**子查询只要能出结果，就立刻返回TRUE，终止子查询**==
